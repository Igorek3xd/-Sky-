# ThermoBox — размеры платы для корпуса (Fusion 360)

Файлы в этой папке:

| Файл | Что это |
|---|---|
| `ThermoBox_board.step` | 3D-модель платы с компонентами. Импорт: Fusion → Insert → Insert Mesh/CAD → STEP |
| `ThermoBox_outline_mm.dxf` | Контур платы 1:1 в миллиметрах (Insert → Insert DXF → на эскиз) |

> **В STEP нет моделей USB‑C (HRO TYPE‑C‑31‑M‑12) и JST‑PH**: в библиотеке KiCad нет их 3D‑моделей.
> Во Fusion поставь на их место простые прямоугольники по размерам из таблицы ниже.

## Система координат (используется во всех таблицах)

* **Начало (0,0)** — левый нижний угол основного прямоугольника платы (угол со стороны USB‑C).
* **X** — вправо, **Y** — вверх, в сторону экрана. **Z** — вверх от *нижней* поверхности платы.
* Плата смотрит компонентами вверх; толщина PCB **1,6 мм** (верхняя поверхность — Z = 1,6).
* Перевод из координат KiCad: `X = x_kicad − 100`, `Y = 164 − y_kicad`.

## Контур платы

| Элемент | X, мм | Y, мм | Примечание |
|---|---|---|---|
| Основной прямоугольник | 0 … 38 | 0 … 64 | скругления углов R 2 |
| «Язычок» датчика SHT40 (голова) | −11 … −4 | 51,5 … 61,5 | левые углы R 1 |
| Перешеек язычка | −4 … 0 | 54 … 59 | ширина 5 мм — тепловая развязка |
| Габарит всей платы | −11 … 38 (49,0) | 0 … 64 (64,0) | |

## Отверстия под крепёж (M2, отверстие Ø 2,2, без металлизации)

| | X | Y |
|---|---|---|
| H1 | 2,6 | 61,4 |
| H2 | 35,4 | 61,4 |
| H3 | 2,6 | 40,0 |
| H4 | 35,4 | 41,4 |

Около H1–H4 нет меди в радиусе 2,5 мм: подходят стойки Ø 4–5 мм и саморезы M2 или винты M2×5.
Нижний край платы зажимается рёбрами корпуса; USB‑C дополнительно держит его при подключении кабеля.

| Что | Где | Размеры / центр | Вырез в корпусе (рекомендация) |
|---|---|---|---|
| **USB‑C** J1 | нижняя стенка | центр X = 19,0; разъём выступает за край на ~0,6 мм; корпус 8,94 × 7,3 × 3,26 мм; центр отверстия Z ≈ 3,2 | 9,8 × 4,0 мм, R 1,6. Если стенка толще 1,5 мм — с наружной стороны выборка 12,5 × 6,5 мм под литую часть штекера |
| **Боковая кнопка** SW1 (Panasonic EVQ‑P7A, боковое нажатие) | правая стенка | Y = 52,0; торец толкателя X ≈ 37,7 (на 0,3 мм внутри края); высота корпуса кнопки 1,35 мм над платой → центр толкателя Z ≈ 2,3 | отверстие 4 × 3 мм и толкатель/«язычок на гибкой петле» длиной ≈ (толщина стенки + 0,3 мм) |
| **LED зарядки** D2 (0603, красный) | сверху, вне экрана | X = 7,6; Y = 11,4 | отверстие Ø 1,5–2 мм в крышке или световод |
| **RESET** SW2 / **BOOT** SW3 (Alps SKRK, нажатие сверху, высота 2,0) | сверху | SW2: X 30,5 Y 2,4 · SW3: X 30,5 Y 7,0 | отверстия Ø 1,5 под скрепку (нужны только при прошивке «намертво уснувшей» платы) |
| **Провод аккумулятора** J2 (JST‑PH 2 мм, горизонтальный SMD) | левая сторона, внутрь корпуса | ответная часть входит с края X = 0, центр Y = 18,0; корпус разъёма X 0,3…10,5, Y 13,4…22,7, высота ≈ 4,5 (проверь по даташиту) | 4–5 мм свободного места слева для изгиба провода к аккумулятору |
| **Датчик SHT40** U5 | на язычке | центр X = −8,0; Y = 57,5 | отдельная камера: перегородка по линии X ≈ −2 с прорезью 6 × 2,5 под перешеек + вентиляционные щели 1 × 8 мм в стенке и крышке над язычком |
| **Антенна Wi‑Fi/BLE** ESP32‑C3 | правый край | X 31,4…38, Y 15…33 | не ставить рядом металл (винты, магниты, фольгу) |

## Экран 0,96" OLED (модуль SSD1306, 4 вывода GND‑VCC‑SCL‑SDA)

| Параметр | Значение |
|---|---|
| Пины модуля J3 | шаг 2,54; пин 1 (GND) X = 15,19 · пин 4 (SDA) X = 22,81; Y = 61,4 |
| Модуль (типовой 27,3 × 27,8 мм) | X 5,35 … 32,65; Y ≈ 34,9 … 62,7 |
| Высота | пластиковая проставка штыревого разъёма 2,5 мм → плата модуля Z = 4,1 … 5,3 → стекло ≈ до Z 6,9–7,3 |
| Под экраном | только низкие детали (≤ 1,2 мм): резисторы/конденсаторы 0603, Q2 SOT‑23, R13/C9 |

> Модули 0,96" разных продавцов отличаются на ±0,5 мм и положением окна дисплея.
> **Обязательно перемерь свой модуль штангенциркулем**: внешний габарит, окно стекла, видимую область (обычно ~21,7 × 10,9 мм) и её смещение относительно пинов.

## Высоты компонентов над платой (Z от верхней поверхности PCB)

| Компонент | Высота |
|---|---|
| ESP32‑C3‑WROOM‑02 (U4) | 3,2 |
| USB‑C (J1) | 3,26 |
| JST‑PH SMD (J2) | ≈ 4,5 |
| Диод SS14 SMA (D1) | 2,2 |
| Кнопки SKRK (SW2, SW3) | 2,0 |
| SOT‑23‑5 / SOT‑23‑6 | 1,1–1,55 |
| Конденсаторы 0805 | 1,25 |

Снизу платы компонентов нет. Наружу на 0,8–1,5 мм торчат только выводы экрана и крепёжные лапки USB‑C (выводы экрана после пайки подкуси).

## Аккумулятор и сборка по высоте

Рекомендуемый аккумулятор: **LiPo 603450, 1000 мА·ч, 3,7 В, с платой защиты и разъёмом JST‑PH 2,0** (6,0 × 34 × 50 мм), под платой.

| Слой (снизу вверх) | Z, мм |
|---|---|
| дно корпуса (внутри) | 0 |
| аккумулятор 6,0 + двусторонний скотч 0,5 | 0 … 6,5 |
| зазор под выводы (стойки) | 6,5 … 8,0 |
| PCB (низ / верх) | 8,0 / 9,6 |
| модуль OLED, верх стекла | ≈ 14,9 |
| внутренняя поверхность крышки | ≈ 15,2 |

Минимальная внутренняя полость: **≈ 50 × 65 × 15,5 мм** (с отсеком датчика); с учётом стенок 1,6 мм корпус ≈ 53 × 68 × 19 мм.

> ⚠️ Проверь полярность провода аккумулятора: у разных продавцов JST‑PH распаян по‑разному.
> На плате: **пин 1 = «+» (VBAT)**, пин 2 = «−» (GND).
